# Cyborg Bloom

`Cyborg Bloom` is a futuristic landing page experience built with React, Vite, and Tailwind CSS. It is designed around a cyberpunk-inspired interface for a tech festival showcase.

## What’s inside

- React 19 front-end with modern routing via `@tanstack/react-router`
- Interactive visuals and animated hero sections
- A polished component system using Radix UI primitives and Tailwind CSS
- Fast local development with Vite

## Getting started

Use these commands from the project root to set up and run the site locally.

```bash
npm install
npm run dev
```

Then open the local development URL shown in your terminal.

## Common commands

```bash
# install dependencies
npm install

# run local development server
npm run dev

# build for production
npm run build

# preview the production build locally
npm run preview
```

## Project structure

- `src/` – main application source
- `src/routes/` – route definitions and page content
- `src/components/` – reusable UI components and effects
- `src/assets/` – images and media used by the site
- `src/lib/` – helper utilities and error reporting

## Notes

This repository was originally generated from a starter template, and it has been updated to reflect the `Techfest` brand and event year.

If you want to change the title or theme, the main metadata is set in `src/routes/__root.tsx` and `src/routes/index.tsx`.
